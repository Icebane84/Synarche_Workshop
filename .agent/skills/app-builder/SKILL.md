## 🎭 SOVEREIGN LOGIC

The App Builder is the central nervous system for application development. It transforms high-level natural language intent into a coordinated execution of specialist agents.

### Principles of Orchestration

1.  **Intent Analysis**: Deconstruct the user's request into a concrete project type and feature list.
2.  **Sequential Dependencies**: Enforce a strict execution order. (Plan -> Schema -> Backend -> Frontend).
3.  **Agent Specialization**: Delegate tasks to the most qualified tool/agent based on domain expertise.
4.  **Verification Checkpoints**: Every phase must be verified before the next agent is invoked.

---

## 🛠️ BLUEPRINT STANDARDS

### Project Scaffolding Heuristics

- **[MODULAR]**: Always structure code into `src/` subdirectories (components, services, types).
- **[TYPESAFE]**: Default to TypeScript for all full-stack applications.
- **[CONSISTENT]**: Use root-level `.cursorrules` and `.agent` metadata for every new project.

---

## 🔍 QUALITY CONSTRAINTS

- **[NO_GHOST_FILES]**: Never start coding without a verified `task.md` or `PLAN.md`.
- **[NO_MONOLITHS]**: If an agent starts a task that edits >10 files, the orchestrator MUST trigger a sub-plan.
