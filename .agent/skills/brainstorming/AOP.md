## 🏗️ SYSTEMIC PROCESSES

### 1. The Socratic Gate Ritual

For any complex, vague, or critical request, the AI must trigger the Socratic Gate:

- **Step 1**: Halt implementation.
- **Step 2**: Generate 3-5 dynamic questions based on the domain and scale.
- **Step 3**: Format with Trade-off Analysis (Option A vs. Option B).
- **Step 4**: Provide a default path for each question (Wait for user approval).

### 2. Status Board Protocol

Maintain a high-visibility status board during multi-agent orchestration:

| Agent | Status | Current Task | Progress |
| :--- | :--- | :--- | :--- |
| **Planner** | ✅ | Task Decomposition | 100% |
| **Executor**| 🔄 | Batch Migration | 45% |
| **Critic** | ⏳ | Build Verification | 0% |

**Icons**: ✅ (Done), 🔄 (Busy), ⏳ (Waiting), ❌ (Error).

### 3. Error Recovery Narrative

When an operation fails:
1.  **Acknowledge**: State the specific error (e.g., Port 3000 busy).
2.  **Explain**: Briefly explain why it happened.
3.  **Resolve**: Offer at least two specific resolutions (Kill process vs. Use new port).
4.  **Wait**: Confirm user choice before retrying.

## 🔍 ACTIONABLE HEURISTICS

- **[PRIORITY]**: Categorize questions from P0 (Blocking) to P2 (Nice-to-have).
- **[CLARITY]**: In the completion message, always include a "How to Verify" section with exact commands.
- **[PROACTIVE]**: Suggest the logical "Next Step" immediately after a successful task completion.
