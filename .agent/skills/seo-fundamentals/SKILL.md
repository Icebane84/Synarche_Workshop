## 🔴 MANDATORY OPERATIONAL PROTOCOLS

### 1. "Semantic-First" Mandate
**MANDATORY**: Use standard HTML5 landmarks (`<main>`, `<nav>`, `<section>`) before custom `<div>` structures. Enforce a strict H1-H4 heading hierarchy.

### 2. Metadata Uniqueness
**MANDATORY**: Every route MUST have unique, contextual `<title>` and `<meta description>` tags. No generic placeholders.

### 3. Core Web Vitals Blocking
Any implementation that causes over **100ms INP** or **0.1 CLS** shift must be flagged and refactored using skeletons or dimension pre-allocation.

### 4. Schema-First (JSON-LD)
Mandate `Schema.org` structured data for all primary assets (Organization, Application, Breadcrumbs).
