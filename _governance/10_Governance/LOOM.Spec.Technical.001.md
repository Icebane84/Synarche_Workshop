## 1. Introduction & Conceptual Framework

### 1.1 Purpose

This document serves as the single source of truth for the **Cognitive Loom** application. It provides a comprehensive
technical overview of the system's architecture, visual design, state management, and core functionalities.

### 1.2 The Cognitive Loom Metaphor

The Cognitive Loom is conceptualized as a living, celestial AI architecture where abstract cognitive functions are
represented as celestial bodies—stars, planets, and moons—interconnected by threads of data and influence.

### 1.3 Ontological Glossary

- **Coherence**: The baseline state of stable, harmonious, and synergistic processing.
- **Dissonance**: A corrective, system-wide shockwave initiated by defense components to purge errors or fallacies.
- **Synthesis**: Weaving multiple streams of data and knowledge into a unified understanding within `CoreEngine`.
- **Transcendence**: Significant leap in system capability triggered by integrating authoritative external sources.
